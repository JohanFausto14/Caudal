# Finanzas - Administración de Negocio Gastronómico

Proyecto integral de finanzas y punto de venta para negocio de comida.

## Estructura
- `/front`: Frontend en React 19 + TypeScript + Vite
- `/back`: Backend en Node.js + Express + Mongoose (MongoDB)

## Comandos Rápidos
```bash
# Iniciar frontend y backend juntos
npm run dev

# Iniciar solo frontend (http://localhost:5173)
npm run dev:front

# Iniciar solo backend (http://localhost:5000)
npm run dev:back
```
